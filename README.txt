HALLOWEEN COUNTDOWN — GITHUB PAGES

1. Create a new public GitHub repository (e.g. halloween-countdown) or choose your existing countdown repository.
2. Upload index.html at the top level of the publishing folder. Do not overwrite the index.html for your unrelated existing website.
3. Settings -> Pages -> Build and deployment -> Source: Deploy from a branch; Branch: main; Folder: /(root); Save.
4. Open the exact site URL listed on Settings -> Pages. For a project repository it is usually https://USERNAME.github.io/REPOSITORY/
5. Check the Actions tab for deployment errors; publishing may take several minutes.
6. The page uses 20:00 GMT (UTC), annually on 31 October; edit EVENT_SETTINGS at end of index.html.
